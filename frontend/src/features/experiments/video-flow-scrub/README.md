# Video flow scrub

Scroll-scrubbed video that looks continuous at any scroll speed: frames between two decoded video
frames are synthesised in a shader from precomputed optical flow.

[http://localhost:3000/lab/video-flow-scrub/](http://localhost:3000/lab/video-flow-scrub/) (prototype, not listed in the lab grid)

## How it works

- `underwater2_color.af`: the unique frames of the source video packed with
  [ActiveFrame](https://github.com/activetheory/activeframe) (H.264, decoded with WebCodecs).
- `underwater2_flow.af`: one frame per color frame `i`, a grayscale 2×2 atlas with the forward
  (`i → i+1`) and backward (`i+1 → i`) flow at half resolution. Each pair is normalised to its own
  range, the ranges live in the `.af` manifest (`manifest.flow.scales`).
- Scroll gives a fractional position `i + t`. Three decoders keep frame `i`, frame `i + 1` and flow `i`;
  the three textures are swapped together so the shader never mixes two pairs.
- Shader (`Demo.ts`): intermediate flows `t→0` / `t→1` from both directions
  (Super SloMo approximation), backward-warp both frames and blend by `t`. Optional forward/backward
  consistency weights for occlusions (off by default: on this footage it measured slightly worse).
- Modes: no interpolation (nearest frame), crossfade, optical flow.

Assets are generated by `scripts/video-flow/build.sh`, see [its README](../../../../scripts/video-flow/README.md).
